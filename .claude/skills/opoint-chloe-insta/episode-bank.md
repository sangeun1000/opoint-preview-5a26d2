# 조합표 · 로테이션 로그

매 편 5칸을 하나씩 고른다. **직전 편과 최소 2칸은 달라야** 하고, 연속 3편 안에서 ③ 형식과 ④ 결말은 겹치지 않아야 한다.

## ★ 보석 이야기는 일주일에 한 편 (2026-09-30 상은님)

> *"클로이 보석이야기는 일주일에 1번만. 나머지는 다양한 앵글의 일상 이야기를 하게 해줘"*

**세는 법** — 칸 번호와 무관하게 **광물이 그 편의 주인공이면 보석 편**이다.
`X5 광물 접사` · `X7 홀로그램 광물 도감` 은 언제나 보석 편이고, `F2 전문가 모드`·`F4 수집벽` 도
광물을 다루는 사건과 붙으면 보석 편으로 센다. 채집·가공·착용 중 하나라도 줄거리의 중심이면 해당한다.

**나머지 편은 일상이고, 앵글이 서로 달라야 한다** — 와이드(상황) · 탑뷰·접사(디테일) · 미디엄(감정) ·
로우앵글 · 어깨 너머 중에서 직전 편과 다른 것을 고른다. 셀카는 쓰지 않는다(2026-09-29).

**왜 이 규칙이 생겼나** — 자동 일일 계정에서 09-17~09-30 **14일 연속**으로
*"○○을 점검하다가 틈에 끼어 있던 옅은 ○○핑크빛 광물을 발견해 ○○로 깎아 만들고 셀카"* 가 나갔다.
장소·핑크 이름·품목만 바뀐 같은 하루였고 13건이 이미 게재됐다.
⚠️ **«틈에 끼어 있던 … 깎아 만들고» 문형은 쓰지 않는다.**

자동 일일 계정 쪽은 코드가 지킨다 — 트랙 `MINERAL` 이 **일요일 한 번**이고,
`check-chloe-variety.mjs` 가 굽기 전에 횟수와 문형을 센다(`realtime-bot/scripts`).

## ① 관계 (클로이 ↔ 핑핑)

| 코드 | 관계 | 핑핑 표정 흐름 |
|---|---|---|
| R1 | 사고와 짜증: 클로이가 사고 치고 핑핑이 짜증 | 노려보기, 체념 |
| R2 | **역전**: 핑핑이 버그나 고장, 클로이가 수습 | 슬픔, 무표정 |
| R3 | **돌봄**: 핑핑 방전이나 과부하, 클로이가 간호 | 슬픔 → 하트 |
| R4 | **대결**: 핑핑 스캐너 대 클로이의 감 | 분노 → 체념 |
| R5 | **공범**: 팀장 몰래 뭔가 꾸밈 | 하트, 무표정(망보기) |
| R6 | **삐짐과 화해**: 돌만 보는 클로이, 삐진 핑핑 | 무표정 → 하트 |
| R7 | **놀림**: 핑핑이 홀로그램으로 흑역사 재생 | 사랑(장난) |
