저장 방법

둘 중 하나
방법 1 — 깃허브에 바로 저장 (사이트가 1~2분 뒤 자동 반영)

깃허브에서 발급한 토큰을 한 번만 입력해 두면, 이후에는 저장 버튼만 누르면 됩니다. 토큰은 이 브라우저에만 저장되고 서버로 보내지 않습니다.

  1. 깃허브 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access 에서 위 저장소만 선택 · Permissions → Repository permissions → Contents 를 Read and write 로
  3. 만들어진 토큰을 위 칸에 붙여넣기 (한 번만)
방법 2 — 파일로 내려받아 직접 올리기

내려받은 overrides.js 를 원드라이브 01_site/src/js/ 에 덮어쓴 뒤, 깃허브_배포.command 를 실행하면 반영됩니다.
